# Explore Pune – Local Travel Explorer

A simple Web Application Development Activity 1 project created using HTML5 and CSS3.

## Files
- `index.html` – webpage structure and content
- `style.css` – CSS3 styling and responsive layout

## How to run
1. Open the project folder in VS Code.
2. Open `index.html` in a browser.
3. For the best experience, use a Live Server extension.

## Technologies
- HTML5
- CSS3
- Responsive Design
